# Future Scope

## 1. Multitemporal Reconstruction

Use observations from multiple dates to reconstruct the current cloudy scene.

## 2. Transformer-Based Models

Compare CNN attention with spatial/spectral transformer architectures.

## 3. Diffusion Models

Explore diffusion-based conditional image reconstruction after a strong supervised baseline is established.

## 4. Uncertainty Estimation

Generate a confidence/uncertainty map so users can identify areas where reconstruction is less reliable.

## 5. Custom Cloud Detector

Train a dedicated cloud/cloud-shadow segmentation network.

## 6. Large-Scale Scene Processing

Move from 256×256 patches to complete Sentinel-2 scenes using tiling and stitching.

## 7. Downstream Task Validation

Measure whether reconstructed images improve:

- land-cover classification
- vegetation monitoring
- water detection
- change detection

## 8. Physics-Informed Constraints

Investigate reflectance and sensor-specific constraints to reduce physically implausible reconstructions.
